# Hospital Appointment Data Analysis

## Overview
This project analyzes hospital appointment data to identify trends, no-show patterns, and neighbourhood-wise appointment distribution.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Features
- Data Cleaning
- Descriptive Analysis
- Trend Identification
- Data Visualization

## Visualizations
- Appointment Status Pie Chart
- Neighbourhood-wise Bar Chart
